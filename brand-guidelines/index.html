How to use the logo

The name

Write the name as Hurfi, with a capital H.

Leave it whole

Do not stretch, rotate, recolor, outline, or add a shadow to the mark.

Match the ground

Do not place the black wordmark on a dark photo, or the white wordmark on a white page.

Clear space

Leave clear space around the logo so it does not touch other text or the edge of a picture.

Questions

Where can I download the Hurfi logo?

On this page. Each logo has its own download, and Download all logos saves every file in one zip.

Which file should I use on a dark background?

Use the white wordmark, Logo on dark backgrounds, or the white lockup.

What color is Hurfi blue?

The website uses #0076F7. The app icon file uses #007AFF.

What font does Hurfi use?

The brand typeface is PolySans Neutral. The website uses Plus Jakarta Sans and Instrument Serif, both on Google Fonts.

Can I change the logo?
