# Chinese-first build (`scripts/site/`)

hurfi.com is published from `dist/`, built on every Netlify deploy:

```
node scripts/hurfi-pages/zh_mirror.mjs   # Chinese twins in zh/ from the English pages + dictionary
node scripts/site/build.mjs              # assembles dist/
```

| URL | Source in the repo |
|---|---|
| `/…` (default, zh-CN) | `zh/…/index.html` (generated by zh_mirror.mjs) |
| `/en/…` | the English page at the repo root (`…/index.html`) |
| `/zh/…` | 301 to `/…` |

The English pages at the repo root stay the place where pages are written (by hand, `build.py`,
`service_cities.mjs` or the content bot). A page whose Chinese coverage is too low gets a temporary
302 from `/…` to `/en/…` until its strings are translated (`zh_mirror.mjs --missing`).

## One source of truth

`config.mjs` holds everything shared across pages: stats, contact details, address, RMB prices,
the free offer and CTA, the comparison table, the case study, and the fixed trust lines.
`trust-lines.mjs` holds the industry, insight and city-service lines; location lines are
generated from each city's industry links. `build.mjs` writes them into every page in both
languages as static HTML (header language links, footer, consultation form, stats, trust line,
pricing, comparison, case study, client feedback), plus canonical, hreflang (zh-CN, en,
x-default → zh-CN), Open Graph, JSON-LD, `sitemap.xml` and `llms.txt`.

- **Baidu Tongji:** set `BAIDU_TONGJI_ID` in `config.mjs`. Empty means the script is not loaded.
- **Client feedback:** put screenshots in `assets/testimonials/` and captions in
  `assets/testimonials/captions.json` as `{ "file.webp": { "en": "…", "zh": "…" } }`. The section
  stays hidden while the folder has no images.
- **Forms:** Netlify Forms (`project-inquiry`), honeypot `bot-field` plus a time check in `site.js`.
  Email notifications go to the addresses set in Netlify (Forms → notifications).
- **Languages:** `locales.mjs` is the registry. Adding a language = one entry there, its strings in
  `config.mjs` / `trust-lines.mjs`, and a source of translated pages.
- **China Advertising Law:** the build fails if Chinese copy in the config contains 最 / 第一 / 唯一 /
  顶级 / 首选 / 国家级 / 100%, and reports any left in page text (`build-report.json`).
